# 🏋️ Assistente Virtual da Academia

Assistente Virtual Inteligente desenvolvido utilizando HTML, CSS, JavaScript, Node.js, Express e API da OpenAI.

O sistema foi desenvolvido com o objetivo de auxiliar usuários com dúvidas relacionadas à academia, musculação, exercícios, treinamento físico e equipamentos.

---

## 📌 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- OpenAI API
- Fetch API
- LocalStorage
- Markdown
